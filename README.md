# 🚀 MADAR TECH | مدار تك

منصة رقمية متكاملة لمؤسسة **مدار تك (MADAR TECH)** تجمع بين مساحات العمل المشتركة، ركن القهوة الاختصاص، والبرامج التدريبية التكنولوجية، مدعومة بلوحة تحكم إدارية ديناميكية.

## ✨ أبرز المميزات (Features)
- **واجهة مستخدم عصرية ومتجاوبة (Responsive UI):** تصميم متكامل باللغة العربية (RTL) متوافق مع جميع الشاشات.
- **نظام حجز مباشر عبر الواتساب:** إمكانية حجز المقاعد أو التسجيل في البرامج التدريبية وإرسال البيانات تلقائياً عبر WhatsApp API.
- **لوحة تحكم إدارية متكاملة (`dashboard.html`):** تضم 8 وحدات إدارية للتحكم الكامل في محتوى الموقع دون تعديل الكود:
  1. **نظرة عامة والإحصائيات:** متابعة عدد الخدمات، الدورات، والطلبات الواردة.
  2. **سجل الحجوزات والطلبات:** استقبال وتسجيل حجوزات الزوار تلقائياً مع إمكانية تأكيدها.
  3. **إدارة الواجهة الرئيسية (Hero):** تعديل العناوين، الوصف، الأزرار، والصورة الرئيسية.
  4. **إدارة الخدمات:** إضافة وحذف خدمات المساحة المشتركة.
  5. **البرامج التدريبية:** إضافة وحذف الدورات وتحديد ساعاتها ومستوياتها.
  6. **من نحن والمميزات:** تعديل الرسالة، الرؤية، ومميزات المؤسسة.
  7. **بيانات التواصل:** تحديث العناوين، البريد، وأرقام الهاتف والواتساب.
  8. **التحكم في ظهور الأقسام:** إظهار أو إخفاء أي قسم في الموقع بنقرة واحدة.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **HTML5 & CSS3** (Custom Properties & Responsive Grid/Flexbox)
- **Vanilla JavaScript (ES6+)**
- **Web Storage API (`localStorage`)** لمزامنة البيانات الفورية بين لوحة التحكم والموقع الرئيسي.
- **Font Awesome & Google Fonts (Cairo)**

## 📂 هيكلية الملفات
- `index.html` — الصفحة الرئيسية للموقع.
- `dashboard.html` — لوحة التحكم الإدارية.
- `style.css` — ملف التنسيقات والهوية البصرية.
- `script.js` — ملف البرمجة والربط الديناميكي.
- `images/` — مجلد الصور والشعار.
